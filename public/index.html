02 — How they’re built

Three ways onto HarmonyOS.

The seam you choose matters more than the language. These are the three we’ve actually shipped.

01 · Shim

Flutter backport shim

Keep the Dart side untouched. Re-implement the missing GMS platform interface on ArkWeb + Location Kit. Validated in OpenGMaps.

See it inOpenGMaps

02 · Shell

ArkTS shell + NAPI

Wrap C/C++ engines in a Stage HAP. XComponent owns the EGL surface; a thread-safe NAPI queue carries input. Validated in OHEmacs.

04 — Developers

Run it locally.

One dependency (express), no build step. The same JSON the pages use is yours to query.

Terminal
$ git clone https://github.com/Abhi-Flex1/AppFactory.git
$ cd AppFactory && npm install
$ npm start

listening on http://localhost:3000
$ curl -s localhost:3000/api/apps | jq '.[].name'

API

RouteWhat you get
GET /api/appsAll dossiers. ?q= and ?stack= filter server-side.
GET /api/apps/:idOne dossier: stack, bundle, install, notes.
GET /api/releases/:idLive GitHub release + .hap assets.
GET /api/contributorsBuilders and focus areas.
GET /healthUptime probe.

Adding a port?

Append to data/apps.json, add yourself to data/contributors.json, open a PR.
