Developers

Run the whole site locally.

Express plus a folder of JSON — one dependency, no build step. The same API that renders these pages is yours to query.

Terminal

$ git clone https://github.com/Abhi-Flex1/AppFactory.git
$ cd AppFactory && npm install
$ npm start

listening on http://localhost:3000
$ curl -s localhost:3000/api/apps | jq '.[].name'

JSON API

  • GET /api/appsEvery dossier. ?q= and ?stack= filter server-side.
  • GET /api/apps/:idOne dossier: stack, bundle, install steps, notes.
  • GET /api/releases/:idLive GitHub release with its .hap assets.
  • GET /api/contributorsBuilders and their focus areas.
  • GET /healthUptime probe.

Adding a port is a pull request: one object in data/apps.json, a builder in data/contributors.json, and a link from the catalogue.
